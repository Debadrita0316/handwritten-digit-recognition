# Results

This directory stores outputs generated by `python src/train.py`.

Expected generated files include:

- `sample_images.png`
- `class_distribution.png`
- `model_accuracy_comparison.png`
- `mlp_training_loss.png`
- `model_results.csv`
- `<model>_confusion_matrix.png`

The project report records the following benchmark results on a 2,000-sample held-out subset:

| Model | Accuracy |
|---|---:|
| MLP Neural Network | 93.25% |
| SVM (RBF Kernel) | 93.10% |
| KNN (k=5) | 89.15% |

These values are reported benchmark results, not hard-coded program output. A fresh run can produce slightly different values depending on the environment.


## Interactive demo

The interactive Streamlit demo is implemented in `app.py`. It uses the saved MLP and scaler generated by `python src/train_model.py`.
